Student Placement Tracker

📌 About the Project

Student Placement Tracker is a Python-based web application developed using Streamlit. It helps colleges manage student placement records, monitor placement status, and analyze placement performance through interactive dashboards and visualizations.

🚀 Features

- View student placement records.
- Track student placement status.
- Categorize students as Placed, In Process, and Not Placed.
- Interactive charts and graphs.
- Placement statistics and data visualization.
- Manage student data using CSV files.
- Simple and user-friendly dashboard.

🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- CSV

⚙️ Installation and Setup

Step 1: Clone the repository

git clone YOUR_GITHUB_REPOSITORY_LINK

Step 2: Open the project folder

cd student-placement-tracker

Step 3: Install dependencies

pip install -r requirements.txt

Step 4: Run the application

streamlit run app.py

Step 5: Open in browser

http://localhost:8501
